## Embidextrous 0.10.1

A fix for a wrong Hall Monitor alert after a server restart. Install over 0.10.0; same app, same signing key. Works with the same plugin versions as 0.10.0; Hall Monitor 2.4.1.0 is recommended (it fixes the cause).

### What's fixed
- **No made-up "used 93%" after Hall Monitor restarts.** After a server restart the plugin reported the previous day's watch time for about 15 seconds, and the phone announced it ("Harper has used 93% of their daily time" while she had watched nothing). The first status after Hall Monitor was unreachable no longer raises a percentage alert or a "used all of their time" alert; the next status decides. Plugin 2.4.1.0 also fixes the plugin side, so even the first status is right.

### Good to know
- A time limit that really is crossed while the phone cannot reach Hall Monitor is announced one status late; a "used all" that happened during that gap is not announced.
