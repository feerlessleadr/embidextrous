## Embidextrous 0.11.0

Time notifications now say why a child's time changed. Install over 0.10.1; same app, same signing key. The reasons need Hall Monitor plugin 2.5.0.0; with an older plugin the app keeps the old wording for added time.

### What's new
- **The extra-time alert says why.** Examples: "15 min added because the Feed Chloe chore was marked completed." (a chore marked done in Home Assistant) and "30 min added manually by a parent." The alert still names the child and how much time is left today.
- **Time taken away is announced too.** "30 min taken away: Traded for play time." or "5 min taken away manually by a parent." The title says the child had time taken away.
- **Same alert, same switch.** The rule is now called "Time was added or taken away" (Settings, Notifications, Hall Monitor). Its id did not change, so your existing switch and rules carry over.
- **Your own buttons are labeled.** The +30 min and -30 min buttons and Undo send "app" as the source, so they show up as a parent changing the time.

### Good to know
- Reasons arrive with the same push as the new time, so there is no delay and no polling.
- The plugin keeps the last 20 changes per child in memory. After an Emby restart it starts empty, and the app only announces changes it sees afterwards.
- The lock screen still shows a generic line without names.
- Needs plugin 2.5.0.0 for reasons and for take-away alerts. Home Assistant needs its updated configuration to send the chore name.
- Checked on an emulator against a test server. Not yet checked on a real phone.
