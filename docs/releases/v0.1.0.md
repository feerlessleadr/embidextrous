## Embidextrous 0.1.0: the first combined release

One Android app for two things on an Emby server: **watch-time limits** for the kids (Watching Eye) and **smart lists** (SmartLists). Sign in once with your Emby account.

### What is in it
- **Watching Eye**: time left per limited user with a live countdown and "now playing", quick +15 / +30 / +60 min or any amount, time-outs and resume, reset, stop stream, and an Undo for the last change. Updates are pushed live from the server (no constant refreshing); if the live connection drops, the app asks the server every 20 seconds instead and says so.
- **Background alerts** (optional, off by default): a notification the moment someone reaches their limit, with buttons to add time. The lock screen shows only a generic notice, and the buttons need the phone unlocked.
- **Home-screen widget** with each limited user's time left, and an option to show "User 1", "User 2" instead of names.
- **Smart lists**: overview, search, refresh, enable/disable, delete with undo, the full list editor (templates, rules and groups, sorts, schedules, preview, share/import, images), backups, a one-tap refresh widget and Quick Settings tile.
- **Roles**: an Emby administrator sees every tool; a regular account sees only Watching Eye (the SmartLists plugin needs an administrator).
- A theme and accent colour (or Material You) shared by the whole app.

### You need
- Emby Server 4.10.1 or newer, reachable over **HTTPS** (the app refuses plain `http://` and follows no redirects).
- The [Watching Eye plugin](https://github.com/feerlessleadr/watching-eye-emby) **1.9 or newer** for Watching Eye (older versions work with fewer features), and the [SmartLists plugin](https://github.com/feerlessleadr/emby.smartlists) **0.1.9 or newer** for smart lists.
- Android 8.0 or newer.

### Moving over from the two older apps
This is a new app with its own name and signing key, so it installs **next to** the old ones and does not replace them. Settings are not carried over: sign in again and paste the Watching Eye key from the plugin page (External API tab). Keep the old apps until you are happy with this one.

### Verify your download
The APK is built by GitHub from this repository, signed with the Embidextrous release key, and comes with a signed build attestation:

```
gh attestation verify Embidextrous-0.1.0.apk --repo feerlessleadr/embidextrous
```

### Known limits
- This version has been tried on an emulator against a test server, not yet on a real phone over HTTPS. Please report anything odd.
- Back from the Smart Lists or Settings tab goes to the Watching Eye tab first.
- A list opened through "Import a shared list" is not treated as changed, so leaving it without saving gives no warning.
- The widget picker shows the app icon as its preview.
