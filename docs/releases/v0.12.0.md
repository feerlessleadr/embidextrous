## Embidextrous 0.12.0

A new Label Maker tab: review the music downloads that need a decision, right from your phone. Install over 0.11.0; same app, same signing key. It needs the Label Maker plugin 0.1.8.0 or newer (0.1.11.0 for live updates) and an Emby administrator account.

### What's new
- **Library > Label Maker.** A status card shows how many albums need review, are Ready, found no match, or failed, when Label Maker last looked at the inbox, and any problem with a lane or with MusicBrainz.
- **Quick switches.** Dry run, Pause and Check inbox now are on the card. Turning dry run off asks you to confirm first, because Label Maker then files matching albums without asking.
- **Albums that need you.** Filter by state (Needs review is the starting point), by lane, or by a search for an artist, album or folder.
- **Review one album.** Open it to see the best match and the other editions Label Maker found, each with how well your files fit. Search MusicBrainz by hand or paste a release link, then preview exactly what filing would do before you do it.
- **Files the library already has.** Choose keep both, replace the old files, or file only the new files. Nothing is overwritten unless you choose Replace, and then the old files are saved in the inbox's `_Replaced` folder.
- **Other actions.** Keep my tags and file it, Skip for now, Check again, Discard to the trash folder and Restore, Undo for a filed album, and Split by album for a folder that holds several albums. Anything that moves files asks first.
- **Live.** With plugin 0.1.11.0 or newer the tab updates by itself within a few seconds of a change. With an older plugin it looks again every 20 seconds.

### Good to know
- A choice you make here is carried out even while dry run is on. Dry run only stops Label Maker from filing albums on its own.
- Settings that change what Label Maker writes or sends (lanes, match thresholds, which alerts the server sends) stay on the plugin's Emby page. Matching a track to a different file by hand is not in the app yet.
- If the plugin is missing or too old, the tab says so and how to fix it.
- Tapping a Label Maker alert is meant to open this tab. That has not been checked yet.
- Checked on an emulator against plugin 0.1.11.0 with a test server. Not yet checked on a real phone, and not yet tried against your real inbox.
