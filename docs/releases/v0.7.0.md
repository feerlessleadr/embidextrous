## Embidextrous 0.7.0

Shows how long each child has really watched, and changes what "Reset" means. Install over 0.6.0; same app, same signing key. It needs **Hall Monitor plugin 2.1.0.0** (released at the same time): update the plugin first (or together); with the older plugin the app keeps its old behaviour.

### What's new
- **Watched totals on Home → Kids today.** Under each child's name: watched today and this week, then this month and this year. They count time actually watched and are not changed by a reset, extra time or a time-out. One footnote says when the plugin started recording; earlier time was not recorded, so the week, month and year totals build up from that day.
- **The same line on the Hall Monitor tab** under each child's time left.
- **Reset now means a fresh day.** The three-dot menu item is "Reset today's time…": it only zeroes today's allowance (and any extra time added today). Before, it also zeroed the week, month and year counters, which made weekly figures look wrong.

### Hall Monitor plugin 2.1.0.0 (released with this)
A permanent per-day ledger of watched time (kept apart from the limits), the totals in the status the app reads, the plugin's own Reset changed the same way, and a "Watched" line on the plugin page. Update it like before: put the new `HallMonitor.dll` over the old one (or use the GitHub updater) and restart Emby.

### Verify your download
```
gh attestation verify Embidextrous-0.7.0.apk --repo feerlessleadr/embidextrous
```

### Known limits
- The totals start counting the day plugin 2.1 first runs. Nothing older was recorded.
- The new card lines were checked by unit tests of the reading and formatting, not on a real phone or an emulator screen.
- Everything listed under 0.4.0 to 0.6.0 still applies.
