## Embidextrous 0.10.0

Notifications are rebuilt. Install over 0.9.1; same app, same signing key. Hall Monitor alerts work with plugin 2.2.0.0 and newer; the new "-30 min" button needs Hall Monitor **2.3.0.0**. The alerts from the other services need the new plugin releases listed below.

### What's new
- **Settings > Notifications.** One screen for everything this phone is told about, with a section per service: Hall Monitor, Label Maker, Plugin manager, Hall Pass, Smart lists, Tracearr and Emby server. Each service has its own switch (off until you turn it on), **Sound and vibration** (opens Android's own screen for that service), **Send a test**, and a list of its alerts. Every alert can have several rules (for example 50% and 80%), be switched on or off, be edited and be deleted.
- **Pause and quiet hours.** "Pause all notifications", and quiet hours (alerts that arrive in them come without sound).
- **Who sees what.** Hall Monitor alerts are for every account. The other services are listed only for an Emby administrator account on the Administrator setup (or Custom with Smart Lists on), the same rule as the Library and Server tabs. A regular account sees only Hall Monitor.
- **Hall Monitor alerts, more of them and clearer.** A percentage alert now says how much was used and what is left, for example "Used 1 h 36 min of 2 h allowed today. 24 min left." (the allowed time includes extra time). New alerts: a time-out started or ended, stopped when the allowed hours ended, started watching, extra time was added, Hall Monitor cannot be reached for N minutes, and a daily summary at a time you choose. Rules can cover every user or chosen users, and one limit (daily, weekly, monthly or yearly) or any.
- **One +30 min button.** The "used all of their time" alert, Home's "reached their limit" row and the Hall Monitor card use **+30 min**. The card's four buttons (+15, +30, +60, Other) became **+30 min** and **-30 min**. "-30 min" takes 30 minutes away, or everything that is left when less than 30 minutes remain, and never goes below zero. With Hall Monitor older than 2.3 it can only take back extra time that was added, and it says so.
- **Alerts from your other plugins.** Label Maker (albums need review, an album failed, a lane has a problem, music lookups are stuck, tagged automatically), the plugin manager (updates ready, an update failed, Emby needs a restart, a run finished), Hall Pass (a scan or apply finished or failed, tracks wait for review), Smart lists (a refresh failed, a run finished, the timer stopped), Tracearr (a rule was broken, a server is down) and Emby (a scheduled task failed).
- **Push first.** Everything arrives by push. The app subscribes to each plugin's event stream (the same way Hall Monitor already works), keeps the number of the last event it saw, and catches up after a gap. A 15-minute check runs only while the background listener is not running, as a failsafe.

### Needs these plugin versions for their alerts
Hall Monitor 2.3.0.0 (the -30 min button), Hall Pass 1.4.0.0, Smart lists 0.1.12, the GitHub Repo Plugin Install plugin (the build with phone alerts) and, once it has them, Label Maker. Older versions keep working; their alerts simply cannot arrive, and the service screen says so.

### Good to know
- Switching a service on never replays old alerts: the app only notes where the plugin's log stands.
- The access token goes to the plugins only inside the encrypted websocket message, never in an address.
- Lock-screen text is still generic; names appear only after unlocking, and the +30 min button needs an unlocked phone.

### Known limits
- Checked on an emulator against a test server (real Hall Monitor, Hall Pass and plugin manager pushes, real counted playback), not on a real phone or lock screen.
- Label Maker's own alerts need a small addition in that plugin (its event subscription); until then only the catch-up and the 15-minute check can deliver them.
- Not exercised live: Tracearr alerts, a weekly or monthly limit firing, the Smart lists "timer stopped" alert and the failsafe check actually running.
- Not built yet: sound per rule (it is per service, in Android's settings), a "Set up another phone" code.
