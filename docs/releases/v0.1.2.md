## Embidextrous 0.1.2

Fixes and polish after the first real-phone test of 0.1.1. Everything else is as in [0.1.1](https://github.com/feerlessleadr/embidextrous/releases/tag/v0.1.1): sign in once with your Emby account; an administrator gets Watching Eye and Smart Lists, a regular account gets Watching Eye.

### What changed
- **A calmer Watching Eye tab.** The accent colour no longer tints the whole tab: the background, the cards and the +15 / +30 / +60 buttons are neutral greys (light and dark), and the bottom bar matches while that tab is open. Your accent colour still shows on the progress bar, the main button and links, and the Smart Lists tab keeps its full accent look.
- **Profile pictures** of the limited users are shown on their cards (the first letter of the name is used when a user has no picture).
- **Poster of what is being watched** beside the title, position and device, as the old Watching Eye app showed.
- **Protection against a wrong key.** The plugin locks its public API for 5 minutes after 5 wrong keys in 5 minutes. After the plugin refuses the Watching Eye key, the app now stops asking for 5 minutes and shows a banner explaining it (and saving a new key tries again at once), so it can no longer lock the plugin out by itself.
- **Battery hint** under "Background alerts", with a button that opens Android's battery settings, for phones that stop background apps.
- The Smart Lists tab no longer has a second settings icon.
- Build tooling: the GitHub Actions used to build the app were updated.

### Upgrading
Install over 0.1.1 (same app, same signing key); your sign-in and settings are kept. Obtainium picks it up by itself.

### Verify your download
```
gh attestation verify Embidextrous-0.1.2.apk --repo feerlessleadr/embidextrous
```

### Known limits
- 0.1.1 was tried on a real phone; the changes in this release have so far been checked on an emulator against a test server only.
- Back from the Smart Lists or Settings tab goes to the Watching Eye tab first.
- A list opened through "Import a shared list" is not treated as changed, so leaving it without saving gives no warning.
- Needs Watching Eye plugin 1.9 or newer; older plugin versions are not supported by this app.
