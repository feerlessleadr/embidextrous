## Embidextrous 0.8.0

Faster ways to work through a big Hall Pass review queue, and clearer instructions. Install over 0.7.0; same app, same signing key. It needs the **Hall Pass plugin 1.2.0.0** (released at the same time): the Hall Pass tab now asks for that version or newer and says so otherwise. Update the plugin first, or together.

### What's new in Library → Hall Pass
- **Swipe review.** "Swipe through these N" opens a full-screen view that shows one track at a time and why Hall Pass was unsure. Swipe right for clean, left for explicit (or use the buttons), Skip leaves it for later, Undo takes the last decision back. It works through whatever the list behind it shows: the filters, the reason, the search, an opened album or artist, and the order.
- **Most played first.** Order the list A to Z or by how often it has been played (all your Emby users added up), so what you actually listen to is decided first. Plays show on the cards.
- **Artists view** next to Tracks and Albums: one decision covers everything by an artist.
- **Decide all in this view.** "All N explicit" and "All N clean" apply to every track the current view matches, on every page, after a confirmation that spells out the view (for example "Needs review · No evidence").
- **Needs review by reason** (No evidence, Some sign, Sources disagree, Faint sign of clean) with counts, so a big queue can be taken in groups.
- A **"What to do next"** card says which step you are on (scan, review, preview, turn dry run off on the plugin's Emby page, apply) with all the steps one tap away, and the dry-run message says exactly where the switch is. The Apply button no longer gets cut off on a narrow phone.
- The small footnote about when watched totals started counting is gone from Home → Kids today.

### Hall Pass plugin 1.2.0.0 (released with this)
Words in a track's title now count as evidence (a title like "Fuck You Tom" is no longer "no evidence"); `.lrc` and `.txt` lyric files next to a track are read when Emby lists none; a track with no lyrics now says what was looked for; the Artists view and "Most played first"; a how-to card and clearer dry-run text on the plugin page. After updating the plugin, press "Scan now" once: every track is looked at again, and do a hard refresh (Ctrl+F5) of the plugin page if your browser still shows the old one.

### Known limits
- The swipe gesture, the new chips and the confirmation texts were not tried on a real phone; the logic behind them (swipe threshold, view description, reading the plugin's answers) is unit tested, and the plugin side was checked live on a test server.
- The Hall Pass tab no longer works with plugin 1.1.x (it shows the "too old" message); the rest of the app is unaffected.
- Everything listed under 0.4.0 to 0.7.0 still applies.
