## Embidextrous 0.9.1

A fix for the notification rules in 0.9.0. Install over 0.9.0; same app, same signing key. It works with Hall Monitor plugin 2.2.0.0 (and, for the closest limit only, older plugins), as before.

### What's fixed
- **No alert for a limit that is already used up.** In 0.9.0, adding or switching on a percentage rule alerted at once for any limit already over that percentage. A limit stays at 100% until it resets (3 a.m. by default), so you could get "has used 100%" alerts for a child who stopped watching hours ago. A rule now notes where things stand the first time it is switched on and says nothing about that. It alerts only when a limit crosses the percentage afterward. Switching a rule off and on again starts fresh.
- **The 100% alert says what is true.** It said "Playback is still allowed" even when the time was all used up. At 100% it now reads "has used all of their daily time" and says playback is stopped until that time resets or you add more. Below 100% it still says playback is still allowed.
- **It points to the right place.** The alert told you to change it in Settings > Notifications, which does not exist. It now says "Settings, under Hall Monitor", where the rules are.

If you switched on a rule in 0.9.0 and got alerts straight away, you do not need to do anything after updating. Those alerts will not repeat.

### Known limits
- The fix is covered by unit tests (including the exact case above); it was not tried on a real phone.
- Everything listed under 0.9.0 still applies: quiet hours, per-rule sound and priority, and rules for chosen users only are not built yet.
