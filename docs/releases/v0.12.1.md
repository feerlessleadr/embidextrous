## Embidextrous 0.12.1

A small fix for Hall Monitor. Install over 0.12.0; same app, same signing key.

### What changed
- **No bottom message when you add or take away time.** The message at the bottom of the screen used to cover the buttons, so you could not add or remove time for the next user until it went away. Adding and taking away time now show no message. The card's countdown and minutes show the change. Undo for these two actions is gone; to reverse a change, use the opposite button or the plugin page.
- Failed changes still show a message at the bottom. Time out, reset, stop and bedtime keep their messages and Undo.

### Good to know
- Checked by unit tests only. Not yet checked on an emulator or a real phone.
