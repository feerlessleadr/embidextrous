## Embidextrous 0.3.0

A new look, new Home cards for administrators, and a Server area. Updating from 0.2.0 keeps your sign-in and settings.

### What's new
- **A more designed look.** New sign-in and "how will you use this app" screens, rounded cards with icon badges everywhere, and progress rings of time left around each child's picture.
- **Neutral colours, your accent for highlights.** Surfaces are the usual dark greys (light greys in light mode) and the accent colour you pick in Settings is used only for highlights: buttons, the selected tab, switches and rings. Every tab and the home-screen widgets follow it, in light and dark.
- **Administrator cards on Home**: Smart lists (counts, what failed, the first few lists, Refresh all), Server (Emby version, who is connected, scheduled tasks) and Plugins (versions, with a warning when Hall Monitor is too old for the app). **Customise Home** (the sliders icon) lets you switch cards off and reorder them.
- **Grouped navigation.** The bottom bar is now Home, Watching, Library, Server and Settings (a Parent phone keeps just Home, Watching and Settings), and sections live as tabs along the top, so there is room for new services.
- **Server** (administrator): **Live** (who is playing, direct play or transcoding and why, Stop a stream), **Tasks** (run or stop scheduled tasks, failures first), **Activity** (the server log with filters; failed sign-ins stand out), **Devices** (every app and browser that signed in, Sign out), **Plugins**, and a header with the Emby version and Restart Emby. Everything that changes something asks first.
- **Library**: Smart lists, and a new **Libraries** tab with how much each library holds and Scan buttons (each asks first).
- **Widget headline**: "All good" (and how many are watching) or "<name> at the limit".
- **Smart list backups** now say what they are (they are backups of your smart lists, not of the app or of Emby) and live in Settings only.

### Upgrading
Install over 0.2.0 (same app, same signing key). Obtainium picks it up by itself. The Server and Library tools need an Emby administrator account and the Administrator (or Custom with Smart Lists) profile on that phone.

### Verify your download
```
gh attestation verify Embidextrous-0.3.0.apk --repo feerlessleadr/embidextrous
```

### Known limits
- Checked on an emulator against a test server only; not yet on a real phone. Not checked: Restart Emby, Scan, and running a task from the app (the test server is shared), a transcoding session, a failed task or failed sign-in, large fonts.
- Plugins installed from GitHub are not checked for updates yet (the plugin manager comes later).
- The Activity (Tracearr) and Tags tabs are planned and do not appear in this release.
- The home-screen widget picker shows a blank preview.
- Needs Hall Monitor plugin 1.9 or newer.
