## Embidextrous 0.5.0

Everything that was called "Watching Eye" is now called Hall Monitor, to match **Hall Monitor plugin 2.0.0.0**, released at the same time. **Update the plugin and the app together:** this app needs plugin 2.0 or newer, and plugin 2.0 does not answer older apps.

### What's changed
- The app talks to the plugin by its new names (web addresses, key header and live messages). With an older plugin the Server card shows Hall Monitor as too old and asks you to update it.
- A Hall Monitor key saved by an earlier version is moved to its new storage place the first time it is needed, so you do not have to type it again.
- Screens, code and documentation use the new name everywhere.

### Updating the server first (plugin 2.0.0.0)
The plugin file is now `HallMonitor.dll`. Delete the old `WatchingEye.dll` from Emby's `plugins` folder (two copies of one plugin stop Emby from loading it), put `HallMonitor.dll` there and restart Emby. If you update through the GitHub Repo Plugin Install plugin, it adds `HallMonitor.dll` but does not remove the old file: delete `WatchingEye.dll` by hand before the restart. The plugin keeps its ID, and on its first start it copies your old settings, watch-time data and log to the new file names (the old files stay in place).

### Upgrading the app
Install over 0.4.1 (same app, same signing key). Obtainium picks it up by itself.

### Verify your download
```
gh attestation verify Embidextrous-0.5.0.apk --repo feerlessleadr/embidextrous
```
