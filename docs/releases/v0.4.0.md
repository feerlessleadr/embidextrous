## Embidextrous 0.4.0

A plugin manager, Tracearr activity, live updates everywhere, and a round of fixes. Updating from 0.3.0 keeps your sign-in and settings.

### What's new
- **Plugin manager** (Server → Plugins), for the GitHub Repo Plugin Install plugin: check for new versions, update one plugin, the ones with updates or everything, put back a previous version, change auto-update, pre-releases and which file to use, add a plugin from a GitHub address or the registries, remove one, see the history, save a GitHub token, and restart Emby when an update needs it. Every change asks first. It needs that plugin's phone API switched on (and a second switch for adding and removing) on the plugin's own page in the Emby dashboard; the app explains this when it is off and cannot switch it on for you, by design. The Plugins card on Home now says how many GitHub plugin updates are waiting.
- **Tracearr** (Watching → Activity): what is playing now, the history (filter by person), violations and each person's numbers, from your Tracearr server. Set it up in Settings → Tracearr (address and an API key made in Tracearr under Settings, Data & API). Read only.
- **Live updates everywhere.** Emby and Tracearr push changes to the app, and the app only asks on a timer while a push connection is down. Live sessions, tasks, the activity log, the devices list, the Home server cards, the plugin manager and the Smart Lists overview all follow pushes now.
- **Alerts clear on every phone.** When someone gets time (from any phone or the dashboard), the "limit reached" notification disappears from every phone with Background alerts on. A stale "+15" button also checks first and adds nothing if the person already has time, so time cannot be given twice.
- **Home links open the right tab** (Open lists opens Smart lists, the Server card opens Live, and so on), and you can **swipe between the tabs** of Watching, Library and Server.
- **Server → Live** shows the poster of what is playing and each person's picture. **Server → Devices**: tap a device to give it a name of your own.
- **New smart lists use the SmartLists plugin's defaults** (list type, media types, limits, refresh mode, sorting, public or not, schedule) instead of the app's own starting values.

### Upgrading
Install over 0.3.0 (same app, same signing key). Obtainium picks it up by itself. Alerts need "Background alerts" switched on in Settings on each phone.

### Verify your download
```
gh attestation verify Embidextrous-0.4.0.apk --repo feerlessleadr/embidextrous
```

### Known limits
- Checked on an emulator against a test server only; not yet on a real phone, and **not against your real Tracearr** (only a stand-in that follows its published API) or a real transcoding session.
- The plugin manager's Update, Update everything, Put back and Restart were not run (they replace files or restart the shared test server); Add and Remove were.
- Not checked live: the tasks push, the library-changed push, and the plugin manager's pushed events during a real run.
- Still asked rather than pushed, because nothing is pushed: a smart-list refresh's progress, library counts, and waiting for Emby after a restart.
- Needs Hall Monitor plugin 1.9 or newer; Bulk tag editing is not built yet.
