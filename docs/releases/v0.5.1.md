## Embidextrous 0.5.1

A small update on top of 0.5.0. Install over it; same app, same signing key. It works with Hall Monitor plugin 2.0.0.0 and the matching 2.0.1.0 released at the same time.

### What's changed
- **Server → Live no longer shuffles.** With two or more people playing, their cards used to swap places every second or so. They now stay in a fixed order: by person, then device.
- **Home's "Watching now" card shows the show's poster** for an episode instead of the episode's thumbnail, the same as Server → Live.

### Hall Monitor plugin 2.0.1.0 (released with this)
The plugin's settings page is listed in the dashboard's Server → Advanced menu again. Update the plugin by putting the new `HallMonitor.dll` over the old one (or through the GitHub updater) and restarting Emby; there is no old file to delete this time.

### Verify your download
```
gh attestation verify Embidextrous-0.5.1.apk --repo feerlessleadr/embidextrous
```

### Known limits
- Everything listed under 0.4.0 and 0.5.0 still applies (not yet used on real phones, not checked against the real Tracearr, not checked against plugin 2.0 on a device).
- The new order and the Home poster are covered by unit tests but have not been looked at on a screen; the dashboard menu entry was checked through Emby's page list, not in a browser.
